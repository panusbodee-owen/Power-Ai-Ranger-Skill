## ตัวอย่างการสั่งงาน

**ทำตามรูปแบบที่สั่ง**

คำสั่ง:

```
เขียนข้อดี 3 ข้อ เป็นรายการ 3 บรรทัดพอดี ขึ้นต้นด้วย '- ' ห้ามมีข้อความอื่น
```

รูปแบบผลลัพธ์ที่คาดหวัง:

```
- ข้อ 1
- ข้อ 2
- ข้อ 3
```

**ผลลัพธ์ JSON ยาว**

คำสั่ง:

```
สร้าง JSON array 12 รายการ คีย์ id, name ตอบ JSON ล้วน
```

รูปแบบผลลัพธ์ที่คาดหวัง:

```
[{"id":1,"name":"..."}, ...]
```

## ข้อผิดพลาดที่ยังพบ (หลังใส่คู่มือ)

- ไม่พบในชุดทดสอบ

ข้อควรรู้ทั่วไป: ตัดข้อความระหว่าง `<think>...</think>` ออกก่อนใช้ผลลัพธ์ และตรวจรูปแบบ (JSON) ด้วยโปรแกรมทุกครั้ง อย่าเชื่อว่าโมเดลทำตามรูปแบบเสมอ

## เรียกใช้ทันที

```bash
export AI_TEAM_KEY_AGY_CLI=...   # ใส่ key ของคุณเอง
curl -s cli://agy/chat/completions \
  -H "Authorization: Bearer $AI_TEAM_KEY_AGY_CLI" -H 'Content-Type: application/json' \
  -d '{"model": "gemini-3.8-flash-medium", "messages": [{"role":"system","content":"<system prompt จากด้านบน>"},{"role":"user","content":"<คำสั่ง>"}]}'
```

```python
import os, json, urllib.request
req = urllib.request.Request('cli://agy/chat/completions',
    json.dumps({'model': 'gemini-3.8-flash-medium', 'messages': [{'role': 'system', 'content': SYSTEM}, {'role': 'user', 'content': BRIEF}]}).encode(),
    {'Authorization': 'Bearer ' + os.environ['AI_TEAM_KEY_AGY_CLI'], 'Content-Type': 'application/json'})
print(json.load(urllib.request.urlopen(req, timeout=120))['choices'][0]['message']['content'])
```
